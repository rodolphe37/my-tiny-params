# Security policy

MyTinyParams runs entirely in the browser and has no backend, accounts or stored user data.
If you still find a vulnerability (for example an XSS through a crafted URL or a flaw in the decoder snippet),
please **report it privately** using GitHub's
[private vulnerability reporting](https://github.com/rodolphe37/my-tiny-params/security/advisories/new)
instead of opening a public issue.

Only the latest version on `main` is supported.

---

MyTinyParams s'exécute entièrement dans le navigateur, sans serveur, compte ni donnée utilisateur stockée.
Si vous trouvez malgré tout une faille (par exemple un XSS via une URL forgée, ou un défaut du snippet décodeur),
merci de la **signaler en privé** via le
[signalement privé de vulnérabilité](https://github.com/rodolphe37/my-tiny-params/security/advisories/new) de GitHub
plutôt que par une issue publique. Seule la dernière version de `main` est prise en charge.
